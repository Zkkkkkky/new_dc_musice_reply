# 忍者龙剑传《鲜烈之龙（4-2）》（精修通用驱动）

本目录保存从用户提供的单曲 NSF 转换得到的同驱动 NSF，以及可编辑的 FamiStudio 4.5.3 文本工程。

- 成品使用 `$F000/$F100/$F160` 入口。
- 4 KiB 驱动页除 `$000/$003/$004` 三个 DPCM 数据布局配置字节外，其余 4093 字节与 ROM 精修曲公共驱动逐字节相同。
- `projects/` 中保留两个原始 DPCM 采样：257 字节与 513 字节；采样内容和 197 次触发时刻均已校验。
- 原始 NSF 不进入仓库，源文件 SHA-256 记录在验证报告中。

可重建方法与验证口径见 `docs/鲜烈之龙精修驱动转换.md`。
