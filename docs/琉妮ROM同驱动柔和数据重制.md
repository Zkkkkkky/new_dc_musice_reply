# 琉妮 ROM 同驱动柔和数据重制

## 目标

把“更柔和”版 `Flapper Girl - 琉妮精修.nsf` 的听感重建到歌曲数据中，同时把 NSF 驱动恢复为当前 ROM 精修曲使用的 `$F000/$F100/$F160` 公共驱动。本轮只生成独立 NSF，不修改或替换任何 ROM。

## 实现

原“更柔和”版保持曲目数据不变，在驱动写入 `$4000/$4004/$400C` 前按音高和占空比查表调整音量。重建工具 `tools/rebuild_flapper_soft_with_rom_driver.py` 执行以下步骤：

1. 仿真源 NSF，确认前奏、循环起止和完整循环长度。
2. 由 FamiStudio 记录柔和驱动实际产生的四声道 APU 状态。
3. 将逐帧音量事件压缩为 128 个去重音量包络，柔化结果由歌曲数据表达。
4. 导出新歌曲数据，并绑定仓库内 ROM 公共驱动的完整 4 KiB 页。
5. 对源文件和重建文件执行逐帧声道语义比较。

## 结果

- 交付物：`dist/music/Flapper Girl - 琉妮精修（ROM同驱动柔和数据版）.nsf`
- 文件大小：16512 字节
- SHA-256：`3AADC8A3F2D5A03B9F7B653790D98ECE94848FDCF76EB5F26629B27BECFD3B3E`
- 驱动 SHA-256：`20C0C421ADCE739DB24D8C9D445FB1FC6052C59668B3405967156833F402D431`
- 循环长度：8523 帧

重建后的歌曲数据为 12 KiB，独立 NSF 可正常使用，但超过当前 ROM 为琉妮分配的单个 8 KiB 数据 Bank。本轮按用户要求不修改 ROM，也不把该文件视为可直接覆盖 Bank `$6C` 的数据源。

## 验证

源“更柔和”版与 ROM 同驱动重建版从相同起始帧比较 13226 帧，方波开关、占空比、音量、音高、扫频，三角波开关与音高，以及噪声开关、音量和周期均为零差异。为满足 FamiStudio Pattern 边界，循环点在等价循环内后移 28 帧，循环长度仍为 8523 帧；开头没有附加静音。NSFPlay 另行渲染 60 秒 WAV；两者平均频谱重心相差约 0.83 Hz，3–6 kHz 能量占比相差约 0.021 个百分点。

机器可读结果见 `evidence/2026-09-20-琉妮ROM同驱动柔和NSF/构建校验.json`。
