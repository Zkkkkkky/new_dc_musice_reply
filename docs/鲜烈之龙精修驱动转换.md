## 转换方法

`tools/convert_ninja_gaiden_to_refined_driver.py` 复用公共转换器并执行以下流程：

1. 按 NSF `$FC00` 非 4 KiB 对齐规则模拟 Bank 映射，执行原曲 INIT/PLAY。
2. 通过完整 CPU、RAM 和 Bank 状态重复确定循环，不按固定时长截断。
3. 用 FamiStudio 4.5.3 捕获实际 APU 演奏，重建为一帧一个时间单位的可编辑工程。
4. 恢复 NSF 导入器遗漏的第二份 DPCM 最后一个 `$FF` 字节，并逐字节锁定两份原采样。
5. 导出标准 NSF，绑定 ROM 接受的精修公共驱动核心。
6. 逐帧比较方波、三角波、噪声，以及 DPCM 的触发时刻、速率、长度和采样内容。

重建示例：

```powershell
python tools/convert_ninja_gaiden_to_refined_driver.py `
  --input-nsf <原始NSF路径> `
  --famistudio <FamiStudio.exe> `
  --pydeps <包含py65的目录>
```

## DPCM 驱动配置说明

无 DPCM 的精修曲可以整页复用锁定驱动。该曲启用 DPCM Bank 切换，FamiStudio 在驱动页偏移 `$000/$003/$004` 写入歌曲专属的数据布局配置。若强行覆盖这三个字节，PLAY 会在 `$F3D2` 失去正常返回。

因此成品保留这三个非代码配置字节，其余 4093 字节均来自 ROM 精修公共驱动页。把三个配置字节归一化后，驱动页 SHA-256 为 `20C0C421ADCE739DB24D8C9D445FB1FC6052C59668B3405967156833F402D431`。
