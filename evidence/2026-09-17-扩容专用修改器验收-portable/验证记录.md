# 新DC扩容专用修改器运行验收

## 测试对象

- EXE：`新DC扩容专用修改器.exe`
- 大小：5,701,632 字节
- SHA-256：`4C7F2980CC780253050174C7A6E00A506C7D1EA29E74B90128BDA9ABD9335947`
- 工作目录：只包含该 EXE 与顶层必要 INI/DAT 配置；不含旧修改器测试 ROM、CDL 或调试文件。
- 打开 ROM：`dist/roms/新DC_刚达机体拼图已生效_验证版.nes`
- ROM 大小：1,310,736 字节
- ROM SHA-256：`7FC4889991BAE2F99308AECFC12A98F10413F6E0F675D0415D4B95607DEF8015`

## 结果

1. 启动页 `SRW2修改器V1.5` 正常出现。
2. “进入修改器”后显示 `SRW2扩容版修改器V1.0` 主窗口。
3. 通过“文件→打开”成功载入测试 ROM，主窗口标题显示完整 ROM 路径。
4. 检测到主 `CPageControl`，自动化切换并记录了三个不同页面。
5. 验收脚本退出码为 0，测试目标进程随后关闭。

`screenshots/` 保存对应窗口截图，`controls/` 保存 UTF-8 控件树和菜单数据。控制台在旧代码页下显示的中文乱码不影响 JSON 中记录的真实 Unicode 窗口标题。

本轮为启动、载入和界面可用性验收，不对正式 ROM 执行保存。CHR 基址 `$080010→$100010` 的 14 处补丁范围由 `tests/test_legacy_modifier_expanded_chr.py` 和补丁审计记录验证。
